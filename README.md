# 项目介绍
本项目是一个基于streamlit的python项目，主要部署在云端，用户可以在浏览器中直接使用。
注意：
1. 本项目主要部署在streamlit cloud上，用户可以在浏览器中直接使用https://wangshuai.streamlit.app/。
2. 本项目的代码是开源的，用户可以在github上查看和修改代码。
3. github限制单个文件大小为100MB。

## streamlit打包的特性
由于项目基于streamlit并打包，打包后的exe文件只发挥python解释器的功能，而代码仍然以.py的python文件存在，在程序运行时才读取.py代码并运行，这就允许用户在pages中不断增加新的.py文件，增加新的功能。

## streamlit cloud 云端免费部署的优劣
streamlit cloud 是streamlit官方提供的免费部署服务，用户可以在streamlit cloud上免费部署自己的streamlit项目，但是有一些限制，比如：
1. 必须要有一个github账号。
2. 受云端限制和安全限制，云端的任何程序都是不能操作用户本地电脑的文件（夹）的，这保护了用户的数据安全，但也造成了一些不便。

关于本地文件的操作：程序中有很多对本地文件的操作，如果程序只在本地运行，可以不受影响，但如果运行在云端，则需要考虑下载问题。

我的处理思路是io.BytesIO() 内存缓冲区 + zipfile.ZipFile 生成压缩包 + 把内存缓冲区交给 st.download_button，全程不落盘，直接提供下载结果。


# 本地浏览器使用说明

1. 用streamlit运行PDF.py

```bash
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
streamlit run PDF.py
```

2. 根据运行窗口生成的网址，或自动打开的网址，在浏览器中打开。
3. 上传pdf文件，根据需求点击按钮，结果展示在网页展示，并自动打开结果文件夹。

## 自定义语法文档——模块化.py

本文档详细说明了在 `pages\6模块化.py` 中实现的自定义模板语法及其解析渲染功能。该模板系统支持变量引用、条件判断和各种交互控件，可用于创建动态内容和表单。所有函数都放到__init__.py中，6模块化.py中只保留具体的template内容。

### 1. 变量引用系统
- 支持基础变量引用和默认值设置
- 变量值自动同步到会话状态

### 2. 条件判断结构
- 支持布尔类型条件判断（基于复选框）
- 支持表达式条件判断（基于变量值比较）
- 支持嵌套的 if-elif-else 结构

### 3. 交互式控件
- 单选按钮组（Radio）
- 下拉选择框（Select）
- 布尔判断
- 条件判断

### 4. 变量管理
- 所有变量统一存储在 `default_values` 字典中
- 支持变量值的自动保存和恢复

### 语法规范

#### 1. 变量引用

```
{{ 变量名 }}
{{ 变量名|default=默认值 }}
```

- **变量名**：支持英文字母、数字、下划线和中文字符
- **默认值**：可选参数，当变量未提供值时使用的默认内容
- **默认值分隔符**：仅支持等号(`=`)格式

**示例**：
```
{{ 用户名 }}
{{ 项目状态|default=未开始 }}
```

#### 2. 条件判断

##### 2.1 布尔类型条件判断

```
{% if 条件名 %}
  条件成立时显示的内容
{% else %}
  条件不成立时显示的内容
{% endif %}
```

- 渲染时会创建一个复选框，用户可以勾选表示条件成立
- 条件名会作为变量存储在 `default_values` 字典中

**示例**：
```
{% if 有信访 %}
  〔信访处理〕 存在相关信访事项。
{% else %}
  〔信访处理〕 未收到相关信访事项。
{% endif %}
```

##### 2.2 表达式条件判断

```
{% if 变量名 = "值" %}
  条件成立时显示的内容
{% elif 变量名 = "其他值" %}
  其他条件成立时显示的内容
{% else %}
  所有条件都不成立时显示的内容
{% endif %}
```

- 支持多个 `elif` 分支
- 条件值需要使用双引号包围
- 比较操作符目前只支持等号(`=`)，比较变量值与指定字符串

**示例**：
```
{% if 信访渠道 = "来信" %}
  情况1：来信了{{来信内容}}
{% elif 信访渠道 = "来访" %}
  情况2：来访了{{来访内容}}
{% else %}
  其他信访渠道
{% endif %}
```

#### 3. 交互式控件

##### 3.1 单选按钮组

```
{% radio 组名 %}
选项1|选项2|选项3
{% endradio %}
```

- **组名**：控件的变量名，用于在会话状态中存储用户选择的值
- **选项**：使用竖线(`|`)分隔的选项列表
- 渲染时会创建水平排列的按钮组
- 默认选中第一个选项

**示例**：
```
{% radio 信访渠道 %}
来信|来访|网上信访|电话信访
{% endradio %}
```

##### 3.2 下拉选择框

```
{% select 列表名 %}
选项1|选项2|选项3
{% endselect %}
```

- **列表名**：控件的变量名，用于在会话状态中存储用户选择的值
- **选项**：使用竖线(`|`)分隔的选项列表
- 渲染时会创建标准的下拉选择框
- 默认选中第一个选项

**示例**：
```
{% select 信访类型 %}
征地补偿|安置方案|土地权属|违法占地
{% endselect %}
```

### 变量管理机制

1. **统一存储**：所有变量值统一存储在 `st.session_state.default_values` 字典中
2. **自动保存**：用户的选择和输入会自动保存到会话状态
3. **跨组件共享**：变量可以在不同的组件和条件分支之间共享

### 使用说明

1. **创建模板**：按照上述语法编写模板内容
2. **解析渲染**：将模板传递给 `ast()` 函数解析，然后用 `render_content()` 函数渲染
3. **用户交互**：用户可以通过点击按钮、选择下拉框、填写文本等方式提供输入
4. **获取结果**：变量值会自动保存到 `st.session_state.default_values` 字典中，可用于后续处理

### 注意事项

1. 所有控制标签使用 `{%` 和 `%}` 包裹，变量引用使用 `{{` 和 `}}` 包裹
2. 条件判断标签必须正确闭合（`{% if %}` 对应 `{% endif %}`）
3. 选项列表中的分隔符必须是竖线(`|`)，不要有多余的空格
4. 表达式条件判断的值必须用双引号包围
5. 模板解析错误时会显示错误提示，请检查语法是否正确

### 高级功能

1. **嵌套条件**：支持条件判断的嵌套使用
2. **变量复用**：一个变量可以在模板中多处引用，保持值的一致性
3. **默认值继承**：如果变量在会话状态中已存在，会优先使用已有值
